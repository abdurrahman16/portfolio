About me

I'm a web developer and software engineer who enjoys turning ambiguous problems into clean, working software. My background spans both front-end interfaces and back-end systems, which lets me reason about a feature end-to-end — from the database schema to the pixel on screen.

I studied Computer Science and have spent my education and early career deliberately widening my stack: modern JavaScript frameworks on the front end, Node.js and Java/Spring Boot on the back end, and relational and document databases underneath. I care about code that's easy to read six months later, not just code that works today.

What keeps me in this field is the feedback loop — writing a line of code and seeing it become something a real person can click, use, and rely on. I'm currently looking for a team where I can keep building that kind of software at a higher level.
